# EcoBilling.Control: правила для ИИ и разработчиков

## Назначение

Этот репозиторий содержит центральный сервис EcoBilling. Он выполняет только:

- разрешение кода округа в доверенный адрес `EcoBilling.Api`;
- управление реестром округов системным администратором;
- создание первого директора и сброс его пароля через защищённый внутренний API округа.

Не добавляйте сюда жителей, контроллеров, лицевые счета, счётчики, показания, тарифы, начисления или платежи. Эти данные принадлежат отдельному экземпляру основного `EcoBilling` каждого округа.

## Архитектура

- `Domain` ни от кого не зависит.
- `Application` зависит только от `Domain`.
- `Infrastructure` зависит от `Application` и `Domain`.
- `Api` зависит от `Application` и `Infrastructure` и является точкой сборки зависимостей.
- Не добавляйте `Worker` или `SharedKernel`, пока не появится подтверждённая необходимость.

## Основные сценарии

- `ResolveDistrict`: принять код, нормализовать его, найти округ и вернуть доверенный API URL.
- `CreateDistrict`: создать уникальный код округа и сохранить адрес его API.
- `UpdateDistrict`: изменить разрешённые данные округа.
- `CreateDirector`: передать команду в защищённый внутренний API округа.
- `ResetDirectorPassword`: запросить сброс пароля директора в его округе.
- `AdministratorLogin`: аутентифицировать системного администратора.

## Безопасность и данные

- Код округа является маршрутизатором, а не способом аутентификации.
- На код округа нужен уникальный индекс.
- Разрешайте только проверенные HTTPS-адреса серверов округов.
- Control не подключается напрямую к PostgreSQL округа.
- Пароли никогда не сохраняются в открытом виде и не записываются в журналы.
- Административные изменения должны попадать в аудит.
- Связь с внутренним API округа должна использовать отдельную сервисную аутентификацию.

## Неопределённые правила

Не придумывайте формат кода округа, срок жизни токенов, способ сервисной аутентификации, политику паролей и процедуру первоначального развёртывания директора без подтверждения.

## Проверка изменений

```powershell
dotnet build EcoBilling.Control.slnx
dotnet test EcoBilling.Control.slnx
```
