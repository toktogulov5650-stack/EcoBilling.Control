# Документация EcoBilling.Control

- `architecture` — границы и зависимости центрального сервиса.
- `database` — центральная PostgreSQL и её ограничения.
- `api` — публичные, административные и исходящие внутренние контракты.
- `business-rules` — подтверждённые правила кодов округов и администрирования.
- `testing` — стратегия тестирования.
- `deployment` — развёртывание Control.
