# ADR (Architecture Decision Records)

Короткие записи решений по вопросам исходного реестра Q1-Q23 (технического задания) и реестра раздела 26
архитектурного документа. Каждая запись переносит уже принятое и задокументированное решение в отдельный
файл — это реструктуризация уже существующего содержания `docs/architecture/ecobilling-architecture.md`,
а не новый анализ. Источник истины по деталям реализации остаётся сам архитектурный документ; ADR здесь —
краткая навигационная запись "что решено и почему", без дублирования всех подробностей.

Не все вопросы исходного реестра Q1-Q23 закрыты; не все закрытые вопросы имеют номер `Q`, под которым они
цитируются в архитектурном документе (некоторые решения раздела 26 записаны только по названию темы, без
явного номера). Здесь перечислены только те вопросы, для которых решение уже принято и явно записано в
архитектурном документе — вопросы вне сферы Control (адреса, счётчики, тарифы, платежи и т.п. -- раздел 26)
принадлежат отдельному репозиторию EcoBilling и не имеют ADR здесь.
